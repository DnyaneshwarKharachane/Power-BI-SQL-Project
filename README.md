
# 🍕 Pizza Sales Project 📊 Power-BI-SQL-Project
Interactive Pizza Sales Dashboard Project

This project analyzes pizza sales data to create an interactive dashboard.  We use Power BI and SQL to gain insights into our business performance.

### 💡 What We Wanted To Know:
* **Key Metrics:** Total Revenue, Average Order Value, Total Pizzas Sold, Total Orders, Average Pizzas per Order. 💰
* **Visualizations:**
    * Daily & Monthly Order Trends 📈
    * Sales by Pizza Category & Size 🍕🍩
    * Top & Bottom 5 Sellers 🏆📉

### 🛠 Tools We Used:
* Excel  2021 📊
* SQL Server 2024 & SSMS 20⚙️
* Power BI (November 2024) 💡

### 💾 Data:
* 48,621 rows of pizza order data. 🍕
* Includes details like pizza name, size, category, ingredients, order date/time, price, etc. 🧾
